# Newton AI — персональный помощник для учёбы

**Newton AI** — прототип мобильного веб-приложения для школьников. Оно помогает изучать школьные предметы, решать задания, отслеживать прогресс и получать понятные объяснения от ИИ-репетитора.

Интерфейс доступен на **казахском, русском и английском языках**.

## Возможности

- Выбор языка и персональных настроек при первом запуске.
- Предметы: биология, английский язык, алгебра, геометрия, физика, химия и информатика.
- Практические задания с вариантами ответа, подсказками и пошаговым разбором.
- ИИ-репетитор **Newton AI**: объясняет темы в формате аналогий, алгоритма или краткого ответа.
- Карта знаний для отслеживания освоенных тем.
- Система мотивации: опыт (XP), уровни, монеты, серия занятий, награды и таблица лидеров.
- Поддержка генерации заданий с помощью Google Gemini при наличии API-ключа.
- Резервные локальные ответы, поэтому основные демонстрационные сценарии работают и без API-ключа.

## Технологии

- React 19 и TypeScript
- Vite
- Node.js и Express
- Tailwind CSS
- Google Gemini API (`@google/genai`)
- Motion и Lucide React

## Запуск проекта локально

### 1. Склонируйте репозиторий

```bash
git clone https://github.com/BAITC-Hacks/hack-8c7ed18a-duocode.git
cd hack-8c7ed18a-duocode
```

### 2. Установите зависимости

```bash
npm install
```

### 3. При необходимости добавьте ключ Gemini

Создайте в корне проекта файл `.env` и добавьте в него:

```env
GEMINI_API_KEY=ваш_ключ_Gemini
```

Ключ не нужно публиковать в GitHub. Файл `.env` должен оставаться локальным.

### 4. Запустите приложение

```bash
npm run dev
```

После запуска откройте в браузере адрес, который появится в терминале. Обычно это [http://localhost:3000](http://localhost:3000).

## Как пользоваться

1. При первом запуске выберите язык интерфейса.
2. На главном экране выберите предмет и тему.
3. Перейдите к практике, чтобы решать задания и получать объяснения.
4. Откройте чат с Newton AI, если нужна помощь с темой или задачей.
5. Следите за прогрессом на карте знаний и зарабатывайте XP и монеты.

## API

Приложение использует следующие внутренние маршруты:

- `GET /api/health` — проверка работы сервера;
- `POST /api/tutor` — ответ ИИ-репетитора;
- `POST /api/generate-task` — генерация учебного задания.
